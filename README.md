Tutorial explicando os algoritmos criados na Atividade de TPA sobre Array:

1) 10 Nomes em Ordem Crescente: Crie uma lista com 10 nomes e use sort() para organizá-los em ordem alfabética crescente.

2) 20 Nomes em Ordem Decrescente: Crie uma lista com 20 nomes e organize-a em ordem alfabética decrescente com sort(reverse=True).

3) 50 Números em Ordem Crescente: Gere 50 números e organize-os do menor para o maior com sort().

4) 50 Números em Ordem Decrescente: Armazene 50 números e organize-os do maior para o menor usando sort(reverse=True).

5) 100 Números Pares: Crie uma lista de 100 números e selecione apenas os pares com uma lista de compreensão [num for num in lista if num % 2 == 0].

6) 100 Números Ímpares: Filtre apenas os números ímpares de uma lista de 100 números usando [num for num in lista if num % 2 != 0].

7) Tabela do Campeonato Brasileiro: Crie uma lista de dicionários para representar os times, incluindo posição e pontuação de cada um, e organize conforme a classificação.
